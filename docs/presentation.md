# Презентация до 10 слайдов: план

1. **Титул.** Онлайн-деканат: фото документа + вопрос → ответ со ссылкой
   на правила. Стек одной строкой, команда и ветки.
2. **Проблема.** Деканат перепечатывает справки вручную, ответ без ссылки
   на правило. Сценарий перевода на 2 курс из кейса.
3. **Пайплайн.** Схема: React → `POST /chat|/analyze` → ML1 OCR
   (PaddleOCR-VL, llama.cpp CPU) → ML2 extract+classify → Backend2 rules →
   ответ + `verification` + источники. Внешних API нет.
4. **Демо 1 — справка об обучении.** Скрин результата по `baton.png`:
   карточка 9 полей, `complete`, `п. 3.1`, подсветка подписи/печати.
5. **Демо 2 — академ-отпуск.** `academic_leave.png`: автотип,
   проверка дат начала/окончания (`date_orders`), `complete`.
6. **Демо 3 — практика + диалог.** `internship_certificate.png`,
   уточняющий вопрос `Что там написано?` без повторной загрузки.
7. **Честный случай.** `Сколько стоит обучение?` → `Ответа нет`,
   `verification: null`. Правило: нет в документе и Положении — не выдумываем.
8. **Бонусы.** Автотип, наклон/тень (VLM+автоповорот), новый тип через
   `rules.json` без кода, подсветка боксов, PDF первой страницей.
9. **Стек и ограничения.** Таблица инструментов из README; честно:
   Положения заказчик не дал — база `п. 3.1–3.3` + шаблон и `RULES_PATH`;
   печать — классика (YOLO-слот готов); LLM только локальные и опциональные.
10. **Сдача.** Репозиторий + `docker compose up --build`, `results.json`
    через `tools/make_results.py` (пример `demo_results.json`), видео 3 мин.
