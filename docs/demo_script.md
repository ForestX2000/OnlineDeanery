# Видео-демо до 3 минут: сценарий

Цель: путь от загрузки фото до ответа на трёх документах + честный случай.
Перед записью: `docker compose up --build -d`, дождаться `llama`
(`docker compose logs llama` → `listening on http://0.0.0.0:8080`),
открыть `http://localhost:5173`, подготовить файлы:
`baton.png` (справка, реальное фото), `demo_docs/academic_leave.png`,
`demo_docs/internship_certificate.png`
(`python -m tools.make_demo_docs --output demo_docs`).

## 0:00–0:20 — проблема и сервис (1 слайд устно)

«Деканат вручную перепечатывает справки и ищет пункты Положений.
Показываю цифрового секретаря: фото + вопрос → карточка полей → ответ
со ссылкой. Всё локально, без внешних API.»

## 0:20–1:00 — кейс 1: справка об обучении, документ в порядке

1. Загрузить `baton.png`, тип — авто, вопрос: `Хватит ли её для перевода на 2 курс?`
2. Показать: таблица полей (ФИО, вуз, программа, даты), подсветка подписи
   и печати на фото, ответ со статусом `complete` и источником `п. 3.1`,
   дисклеймер про решение сотрудника.

## 1:00–1:40 — кейс 2: заявление на академ-отпуск

1. Новое обращение, `academic_leave.png`, вопрос: `Чего не хватает в заявлении?`
2. Показать автоопределение типа и проверку дат начала/окончания.

## 1:40–2:10 — кейс 3: справка о практике + уточняющий вопрос

1. Новое обращение, `internship_certificate.png`, вопрос: `Справка о практике в порядке?`
2. В поле `Уточняющий вопрос` спросить: `Что там написано?`
   Показать ответ-перечень полей из диалога без повторной загрузки.

## 2:10–2:40 — честный случай без данных

Вопрос без файла: `Сколько стоит обучение?` → `Ответа нет... Обратитесь в деканат`,
`verification: null`. Подчеркнуть: система не выдумывает.

## 2:40–3:00 — стек одним экраном

Кадр `docker compose ps` + схема: React → FastAPI-шлюз → PaddleOCR-VL
(llama.cpp, CPU) → regex-поля → детерминированные правила + YOLO-подпись.
«Репозиторий, README, results.json — в описании».
