# 🏛️ OnlineDeanery (Онлайн-Деканат)

Групповой проект для автоматизации процессов деканата с использованием интеллектуального распознавания документов (IDP). Полное окружение проекта контейнеризировано с помощью **Docker**, что позволяет развернуть всю инфраструктуру одной командой.

---

## 🛠️ Архитектура и стек технологий

### 💻 Frontend
* **React 19** + **TypeScript** — фронтенд-фреймворк и строгая типизация.
* **Vite** — быстрый сборщик проекта.
* **Tailwind CSS** + **shadcn/ui** — утилитарный дизайн и современная библиотека UI-компонентов.

### ⚙️ Backend
* **Python 3.11** + **FastAPI** — асинхронный высокопроизводительный REST API.
* **PostgreSQL** — реляционная база данных для хранения учетных записей, логов и метаданных документов.

### 🧠 Machine Learning (Интеллектуальный парсинг документов)
Система использует гибридный подход для извлечения данных из сканов и фотографий документов (справок, заявлений, зачеток):
1. **Pipeline OCR (Распознавание текста):** 
   * **OpenCV** — предобработка изображений (выравнивание `deskew`, улучшение контраста `CLAHE`, удаление бликов и апскейл).
   * **PaddleOCR (PP-OCRv5-ru)** — извлечение кириллического текста и координат (`bboxes`) текстовых блоков.
2. **Extractor & Classifier (Извлечение и классификация данных):**
   * *Baseline:* Классификация по ключевым словам, извлечение по регулярным выражениям (`regex`) и геометрическим эвристикам текстовых блоков.
   * *Fallback-система:* **Meno-Lite-0.1** (через **llama.cpp** в квантовании `GGUF Q4_K_M`) — локальная LLM для разбора сложных неструктурированных полей без использования GPU.
3. **Семантический поиск (RAG):**
   * **intfloat/multilingual-e5-small** — векторные эмбеддинги текстов.
   * **Qdrant** — векторная база данных для быстрого поиска по правилам и регламентам деканата.

## 📂 Структура репозитория

```text
OnlineDeanery/
├── frontend/           # Клиентская часть (React + Vite)
│   ├── src/            # Исходный код интерфейса
│   └── Dockerfile      # Сборка фронтенда на node:22-alpine
├── backend/            # Асинхронный API (FastAPI)
│   ├── app/            # Эндпоинты, бизнес-логика, модели SQLAlchemy
│   └── Dockerfile      # Сборка бэка на python:3.11-slim
├── ml/                 # Сервис распознавания документов (OCR + LLM)
│   ├── models/         # Локальные веса PaddleOCR и GGUF-модели
│   ├── src/            # Скрипты OpenCV, пайплайн извлечения данных
│   └── Dockerfile      # Контейнер с поддержкой C++ зависимостей llama.cpp
├── docs/               # Проектная документация и ТЗ
└── docker-compose.yml  # Главный оркестратор всей микросистемы
```

## 🚀 Быстрый старт (Локальное развертывание)

Для запуска всего проекта необходим только **Docker Desktop**. Локально устанавливать Node.js, Python или СУБД не нужно.

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd OnlineDeanery
```

### 2. Запуск локальной инфраструктуры
Выполните команду в корневом каталоге проекта:
```bash
docker compose up --build
```

### 3. Доступ к интерфейсам и API
* 💻 **Frontend:** [http://localhost:5173](http://localhost:5173) (Доступен Hot-Reload при изменении кода на хосте)
* ⚙️ **Backend API Docs (Swagger):** [http://localhost:8000/docs](http://localhost:8000/docs)
* 🧠 **ML Service API:** [http://localhost:5000/docs](http://localhost:5000/docs)
* 🗄️ **PostgreSQL:** `localhost:5432`
